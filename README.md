# ICT 개발 포트폴리오

인증과 권한을 다루는 서비스 개발, 여러 분석 결과를 연결하는 AI 워크플로, 데이터 검증을 수행한 세 프로젝트를 정리했습니다. 프로젝트마다 제가 맡은 범위와 팀이 함께 만든 범위를 구분하고, 설명에 해당하는 코드와 결과 파일을 연결했습니다.

## 프로젝트와 담당 범위

| 프로젝트 | 해결하려던 문제 | 지원자가 맡은 일 | 먼저 볼 자료 |
|---|---|---|---|
| Referoom · 레퍼룸 | 팀 논문을 공유하고 근거가 있는 답변을 제공하는 연구 지원 서비스 | 회원·팀 API와 JWT 인증, Python 공통 인증·권한·오류·로그, DB, 운영 리포트 | [역할과 구현 근거](referoom/README.md) |
| VentureSignal | 여러 자료의 스타트업 분석 결과를 일관된 투자 검토 보고서로 연결 | 시장성 평가·투자 판단 모듈 초기 구현, 필수 점수 누락 시 총점 산정을 보류하는 처리 | [담당 범위와 팀 기여 구분](venturesignal/README.md) |
| ESS 배터리 수명 예측 | 초기 측정값으로 총 수명을 예측하고 새로운 데이터에서의 한계 확인 | 개인 분석으로 EDA, 라벨 점검, 피처 추출, 그룹 분할 검증, 모델 비교와 오류 분석 | [검증 과정과 결과](ess-battery/README.md) |

## 코드로 확인할 수 있는 내용

### 1. 서비스 인증과 공통 처리

레퍼룸에서는 Spring Boot 인증 서버와 Python 서비스가 같은 기준으로 사용자를 확인하도록 구현했습니다. 회원과 팀 API, JWT 검증, 팀 소속·관리자 권한 확인, 오류 응답 형식과 요청 로그를 담당했습니다. 인증 성공뿐 아니라 잘못된 토큰이나 권한 없는 요청을 차단하는 경로도 테스트에 포함했습니다.

- [Java API·보안·서비스 코드](referoom/auth-server/app/src/main/java/workplace/)
- [Python 공통 패키지와 테스트](referoom/common-py/)
- [회원·팀 DB](referoom/db/migrations/)
- [운영 리포트 집계 코드](referoom/scripts/ops_report.py)

논문 검색·RAG·음성·주요 화면 기능은 팀원들이 담당했습니다. 전체 서비스 결과를 개인의 단독 구현 성과로 제시하지 않습니다.

### 2. 근거와 상태를 함께 전달하는 분석 모듈

VentureSignal에서는 시장성 평가와 투자 판단을 담당했습니다. 분석 결과를 공통 상태 형식으로 전달하고, 필수 점수가 없는 경우 합산 결과가 확정된 것처럼 보이지 않도록 처리했습니다. 제출 코드는 팀의 후속 개선이 포함된 통합 버전입니다. 출처 표시 방식이나 추가 채점 등 후속 고도화는 담당 모듈을 처음 구현한 일과 구분해 설명했습니다.

- [시장성 평가](venturesignal/agents/market_eval/)
- [투자 판단](venturesignal/agents/investment_decision/)
- [공통 상태·점수 관련 테스트](venturesignal/tests/)

### 3. 좋은 검증 점수와 실제 일반화 성능의 구분

ESS 분석에서는 원본 수명 라벨과 보정 라벨을 분리하고, 같은 충전 조건이 학습과 검증에 겹치지 않도록 그룹 단위로 분할했습니다. 선택 모델의 내부 CV MAPE는 10.178%, 별도 hold-out은 9.146%였지만 다른 배치의 최종 평가에서는 26.175%로 커졌습니다. 이 차이와 과대 예측 경향을 숨기지 않고 기록했습니다. 실서비스 배포나 실제 ESS 운영 성과를 주장하는 프로젝트는 아닙니다.

- [분석·피처 추출·모델링 노트북](ess-battery/notebooks/)
- [라벨 점검과 가공 데이터](ess-battery/data/processed/)
- [성능표](ess-battery/results/model_performance.csv)
- [모델 비교·셀별 예측·오류 분석](ess-battery/outputs/modeling/)

## 자료의 성격과 실행 범위

이 저장소는 채용 검토를 위해 기존 프로젝트의 특정 시점 코드를 모은 별도 사본입니다. 과거 Git 이력은 옮기지 않았으며, 최초 커밋은 제출 자료를 정리한 시점이지 모든 기능을 처음 개발한 시점이 아닙니다. 팀 프로젝트의 기여는 각 README에서 역할별로 표시했습니다.

이름·교육 장소가 포함된 제출 보고서, 개인 경로가 담길 수 있는 노트북 실행 출력, 편집기 설정과 직렬화 모델 파일은 제외했습니다. 재현에 필요한 소스·설정 예시·평가 지표·예측 CSV는 유지했습니다. 외부 논문 저자와 데이터셋 제공기관은 연구자료의 출처이며 지원자의 학력 정보가 아닙니다. 제3자 코드의 라이선스 고지는 보존했습니다.

실행 방법과 필요한 외부 데이터·API 설정은 프로젝트별 README에 있습니다. API 키나 실제 비밀번호는 포함하지 않습니다. 저장된 모델 평가 결과는 기존 실험의 결과이며, 이 제출 사본을 만들면서 외부 API 평가나 전체 모델 학습을 다시 실행한 결과로 표현하지 않습니다.

이 자료에는 실제 금융거래 시스템 운영 경험이나 금융업무 적용 성과가 포함되어 있지 않습니다. 인증·권한, 데이터 검증, 결과의 근거와 한계를 설명하는 개발 경험을 보여 주기 위한 자료입니다.

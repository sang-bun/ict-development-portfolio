# 설문 기반 난임 위험 예측 서비스

Spring Boot 백엔드와 FastAPI 추론 서버를 연결한 팀 프로젝트입니다. 사용자의 설문이 모델 입력으로 바뀌고, 예측 결과와 설명 보고서로 전달되는 과정을 다뤘습니다. 이 제출본은 개인 식별 정보와 운영 설정을 제외한 코드 검토용 사본입니다.

## 제가 맡은 부분

제가 중심적으로 맡은 일은 설문 입력을 AI 서버의 요청 형식으로 변환하고, 추론 결과를 저장·조회하는 연동 작업과 서버 배포였습니다. 검사 최종 제출 작업을 정리해 팀에 전달할 때는 범주형 입력 변환, FastAPI 모델 서빙, 점수 표시 방식과 클라우드 배포를 함께 설명했습니다.

여기서는 입력 정규화, API 응답 검증, 결과 저장과 실행 환경 점검 과정을 중심으로 소개합니다. 설명 보고서의 별도 조회를 포함한 아래 구조는 제 담당 부분뿐 아니라 다른 팀원의 기능과 후속 개선도 포함한 팀 통합본입니다.

## 연결한 흐름

1. Spring Boot가 설문 세션을 확인하고 범주형 입력을 추론 서버 요청으로 바꿉니다.
2. FastAPI가 키 이름과 결측 입력을 정리하고 모델이 기대하는 피처 순서를 맞춥니다.
3. 예측 점수와 활성 위험 요인 목록을 반환하면 Spring Boot가 결과를 저장합니다.
4. 설명 보고서는 별도 조회 요청에서 생성합니다. 현재 통합본에는 이미 생성한 설명을 재사용하는 처리도 포함되어 있습니다.

`WebClient`를 사용하지만 AI 호출부에서 `.block()`으로 결과를 기다립니다. 따라서 전체 흐름을 논블로킹·비동기 서비스로 표현하지 않습니다. 위험 요인 목록 또한 현재 코드에서는 입력에 활성화된 플래그를 규칙에 따라 추출합니다. SHAP 기반 설명이나 의학적 인과관계를 검증한 기능으로 소개하지 않습니다.

## 실행 환경에서 확인한 문제

기존 작업 기록에는 로컬에서는 가변 길이로 반환되던 위험 요인이 배포 환경에서 세 개로 고정되어 보인 문제가 남아 있습니다. Spring 응답과 AI 서버 응답을 비교하고, EC2의 실행 프로세스·가상환경을 확인한 뒤 올바른 런타임으로 다시 실행하는 과정을 거쳤습니다. 현재 AI 코드에는 시작 시 실행 커밋을 기록하고, 위험 요인 배열 길이를 확인하는 진단 처리가 들어 있습니다.

이 제출본에는 당시의 운영 로그와 화면 기록을 싣지 않았으므로, 장애 원인과 개선 효과를 코드만으로 전부 재현할 수는 없습니다. 대신 [운영 가이드](ai/OPERATIONS_TOP_FACTORS.md)와 0·1·2·3·7개 배열을 확인하는 mock API 테스트로 현재 응답 계약을 살펴볼 수 있습니다. 이 테스트는 실제 모델의 예측 성능을 검증하지 않습니다.

## 남은 검증 과제와 실행 한계

- 백엔드는 2026년 5월 26일 팀 통합본, AI 서버는 2026년 5월 25일 팀 통합본을 기준으로 묶었습니다. 서로 독립적인 저장소였던 두 서버를 하나의 프로젝트 아래 배치했으며, 원본의 Git 이력은 포함하지 않았습니다.
- 실제 배포 주소는 제외했고, 테스트 이메일은 예약된 예시 도메인으로 바꿨습니다. 운영 설정, 자동 배포 workflow, 빌드 산출물, 시스템 메타데이터, 운영용 smoke 스크립트와 개인·팀 식별 링크가 있는 문서는 제외했습니다.
- 학습 데이터와 남녀 모델 바이너리, 실제 사용자 설문·의료 기록은 포함하지 않았습니다. 코드에 있는 테스트 입력과 문서의 샘플 응답은 API 형식을 설명하기 위한 예시입니다.
- 모델 파일이 없으므로 이 사본만으로 실제 추론은 실행되지 않습니다. 백엔드 역시 별도의 DB·인증·AI·LLM 설정이 필요합니다. 운영 시스템에 연결해 실행하는 제출물이 아닙니다.
- 학습 코드·분할 기준·실험 로그가 포함되지 않아 모델의 예측 성능은 이 사본으로 재현할 수 없습니다. 코드의 규칙 기반 후처리를 임상적으로 검증된 보정으로 설명하지 않습니다.
- 모델의 점수는 연구용 서비스의 출력이며, 개인의 난임을 진단하거나 임상적 위험 확률을 보증하는 결과가 아닙니다.
- 이번 정리는 소스·구조 검토이며 전체 빌드와 통합 테스트 통과를 주장하지 않습니다. 외부 API와 실제 운영 환경은 실행하지 않았습니다.

## 공동 작업과 권리

이 사본은 팀 프로젝트를 지원자의 담당·참여 범위와 함께 보여주기 위한 자료입니다. 인증, 홈 화면, 중간 저장, 미션, 커뮤니티와 후속 리포트 개선도 팀 산출물이며, 프론트엔드 전체 구현을 제 기여로 제시하지 않습니다.

다른 팀원의 기여를 지원자의 단독 저작물로 표시하지 않습니다. 원본에 포함된 제3자 빌드 도구의 저작권·라이선스 고지는 그대로 보존했습니다. 프로젝트 전체에 새로운 오픈소스 라이선스를 부여하는 제출물은 아닙니다.

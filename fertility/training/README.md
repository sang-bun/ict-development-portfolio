# 여성 모델 학습 실험 기록

추론 서버와 별도로 수행한 전처리·모델 학습 과정을 담았습니다. 저는 성별 설문 데이터의 전처리와 파생변수 구성, XGBoost·LightGBM 학습, Optuna를 이용한 탐색을 맡았습니다. 여기에는 보관하고 있던 **여성 모델 학습 스크립트**를 넣었습니다. 남성 모델의 학습·평가 코드나 현재 배포된 모델 바이너리를 대신하는 자료는 아닙니다.

## 코드에서 볼 수 있는 작업

| 작업 | 구현 내용 | 코드 위치를 찾는 이름 |
| --- | --- | --- |
| 조사 자료 통합 | 다섯 조사 주기의 고정폭 DAT·DCT와 CSV를 읽고 컬럼 대소문자·연령 변수명을 통일 | `datasets`, `parse_dct_file`, `df_combined` |

양성 사례가 적어 SMOTE를 시험한 뒤, 합성 표본을 늘리기보다 원본 표본을 유지하면서 학습 가중치를 조정하는 방식으로 전환했습니다. 이 스크립트는 전환 후의 가중치 학습 버전입니다. SMOTE 적용 버전이나 동일 조건의 전후 비교를 재현하는 코드는 포함하지 않았으며, 이 사본을 성능 상승률의 증거로 사용하지 않습니다.

## 사본을 만든 방식

- 기존에 제공한 자료의 첫 번째 Python 코드 블록 전체를 추출했습니다. 첫머리에 이 파일의 성격을 설명하는 주석 4줄과 빈 줄을 추가하고 줄 끝 공백만 정리했습니다. 원래의 실행 로직·주석·출력 문구는 보존했습니다.
- 코드 블록 밖의 평가 결과 표는 옮기지 않았습니다. 평가 방식이 다른 숫자를 확정 성능처럼 제시하지 않기 위해서입니다.
- 코드 본문에 개인 이름·학교·계정·절대 로컬 경로가 없어 식별정보 치환은 필요하지 않았습니다. 데이터셋을 가리키는 상대 경로는 유지했습니다. 성별·연령·학력·소득 등 변수는 설문 데이터의 필드이며 지원자의 개인정보가 아닙니다.
- 아래에 적은 문제를 이번 제출본에서 고쳤거나 재학습한 것으로 표현하지 않습니다. 과거의 주석과 출력 문구도 실제 함수 호출과 구분해 읽어야 합니다.

## 실행 범위

이 파일은 과거 실험을 살펴보기 위한 자료입니다. Python 구문 검사는 했지만 학습을 실행하지 않았습니다. pandas, NumPy, scikit-learn, XGBoost, LightGBM, Optuna, joblib을 사용하며, 당시 패키지 버전과 전체 실행 환경은 이 자료만으로 확정할 수 없습니다. 추론 서버의 `requirements.txt`를 학습 환경의 고정 버전 명세로 보지 않습니다.

실행하려면 코드에 지정된 `./dataset/`의 조사 자료와 사전 파일이 별도로 필요합니다. 스크립트를 실행하면 전처리·탐색·학습을 수행하고 실행 위치에 모델 PKL, 피처 목록 PKL, 중요도 CSV를 생성합니다. 데이터·학습 산출물은 이 제출본에 포함하지 않았습니다.

## 해석에 남아 있는 한계

1. **Focal Loss는 정의만 돼 있습니다.** 함수가 있지만 `XGBClassifier`에 목적함수로 전달되지 않습니다. 원본 출력에 Focal Loss를 사용했다는 문구가 있어도 적용 성과를 주장하지 않습니다.
2. **평가 단계별 가중치 사용이 다릅니다.** Optuna 탐색의 CV AUC는 비가중이고, 최종 테스트의 AUC·Recall 등에는 `w_test`를 전달합니다. 혼동행렬에는 가중치를 전달하지 않습니다. 서로 다른 기준의 수치를 같은 성능 변화로 비교하거나 합쳐 해석하지 않습니다.
3. **임계값 선택에 테스트셋 예측을 사용합니다.** 같은 테스트 결과에서 F1이 가장 큰 임계값을 고르므로, 선택 후 독립 테스트 성능으로 볼 수 없습니다. 별도 검증셋 또는 out-of-fold 예측으로 임계값을 정하는 절차가 필요합니다.
4. **일부 결측 대치가 분할보다 먼저 이뤄집니다.** 중앙값 같은 전처리 통계는 학습 데이터에서 계산해 검증·테스트에 적용하도록 분리할 필요가 있습니다.
5. **조사 주기별 가중치 통합을 더 점검해야 합니다.** 처음 찾은 가중치 컬럼을 쓰는 분기 때문에 다른 주기의 값이 결측 대치될 수 있습니다. 최신 주기에 더 큰 가중치를 줬다는 사실만으로 모집단 대표성이나 시점 변화 대응이 검증된 것은 아닙니다.
6. **학습·서빙의 버전 일치를 재현하지 않았습니다.** 저장된 모델·피처 목록이 없으므로 이 실험의 설정이 현재 추론 모델과 완전히 같다고 단정하지 않습니다. 결과는 임상적 진단 성능을 입증하는 자료가 아닙니다.

학습 과정을 숨기지 않고 보여주되, 실행한 작업과 검증이 더 필요한 부분을 나눠 기록했습니다.
